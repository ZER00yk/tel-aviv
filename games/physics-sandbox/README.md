# Loose Parts

Actual Matter.js rigid-body simulation with props, spring dragging, ragdolls, wheeled vehicles, connected joints, explosive impulses, hazard sensors, bumper triggers, gravity changes, and scene persistence.

## Controls

Choose a tool and click the workshop. Select drags bodies; Joint links two clicked bodies; Delete removes bodies and attached constraints. Left/right drives chassis; Detonate explodes bombs.

## State and trust

Version 1 bounded scene data (up to 150 bodies/250 joints) saves in this game namespace. Export/import JSON supports sharing a scene file.

## First-pass limits

No multiplayer, NPC behavior, public scene gallery, sophisticated joint editor, or fracture simulation; hazards currently destroy dominoes.
