# Signal Foundry

Server-authoritative multi-resource production chain: extractors → Spark → smelters → Alloy → labs → Insight. Efficiency, automation, prestige, and ascension use validated actions. Server-clock offline production is capped at eight hours.

## Controls

Click Capture a spark, build extractors, save Spark for a smelter, then Alloy for a laboratory. Research unlocks efficiency and automation. Prestige requires 10,000 workshop output; ascension requires 10 prestige and 100 Insight.

## State and trust

Progression is stored transactionally in game_states. The client cannot save balances.

## First-pass limits

Balance/content expansion and additional late-game layers remain follow-up work.
