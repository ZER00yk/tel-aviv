# After Hours

Shared real multiplayer rooms for reaction races, five-round trivia, and drawing/guessing. Server timestamps score reactions, answer keys stay private, and only the current drawer receives the word. Solo reaction/trivia warmups and sketch canvas also work.

## Controls

Choose a game, create/join a private room, ready all players, and start as host. Reaction waits for green; Trivia answers one option; Drawing rotates drawer and guesses.

## State and trust

Server-validated match outcomes; local warmups are unranked. Platform sessions/activity are managed by the shell.

## First-pass limits

Memory/word/racing minigames, public matchmaking UI, advanced canvas tools, and reconnect polish remain follow-up.
