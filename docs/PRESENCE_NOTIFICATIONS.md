# Presence and browser notifications

Automatic Away begins after five minutes without input in any connected Tell Aviv tab. Activity comes from pointer, keyboard, touch, wheel and focus events; a tab reports its inactivity age every twenty seconds. The realtime service aggregates the most recent input across that user's live sockets. Returning input restores Online. Explicit Away, Do not disturb and Invisible stay selected until the user changes them. Input timestamps remain internal to Redis and are omitted from presence responses.

Invisible appears as the same sparse Offline response as a disconnected friend. The service checks current profile settings when projecting presence and before sending typing events, including queued typing publications. Public profile and Home activity omit another user's Invisible activity. Game-count queries already omit Invisible users. Persistent messages, shared memberships and participation in an explicitly joined match remain visible as authored content; they do not carry a general online status.

Settings → Notifications contains an explicit browser notification opt-in. Permission is requested only by the Enable button, and a dismissed request is remembered so navigating or reloading does not prompt again. Each account separately controls direct-message, mention/reply/thread and party/game invite desktop alerts. Focus Mode, Do not disturb and an active foreground tab suppress desktop alerts while retaining the in-app notification center. The service rechecks desktop eligibility from fresh account settings for each delivery, covering changes made on another device.

Connected background tabs coordinate through a transactional IndexedDB ledger of up to 128 recent notification IDs per account, with Web Locks scheduling deliveries where available. Distinct concurrent alerts queue independently, while repeat IDs create one alert across tabs. Read/write transactions serialize between renderer processes. When IndexedDB is unavailable, a bounded local-storage ledger and short storage-claim election provide a fallback; browser tags also identify repeated alerts. With durable browser storage blocked, cross-tab deduplication is best effort. Clicking an alert focuses Tell Aviv and opens a validated relative application link.

This is live browser notification delivery, not offline service-worker push. An authenticated connected tab must remain open. Chromium tests stub only the operating-system Notification interface; they exercise actual server deliveries, cross-tab coordination, input inactivity, preferences and privacy. Real operating-system display, other browsers and mobile permission behavior still need device testing.
