# Account data and Focus Mode

Settings → Account downloads a private JSON export of the signed-in user's basic account records, authored messages, private notes/resources and their versions, shares, flashcard schedules and chronological reviews (without review nonces), quiz version/breakdown records, assignment completion history, creations and verified completions, client cloud saves, ranked Ego summaries/progress, own marketplace offers/items/history, own poker history, achievements and currency history. It includes own Creator grants/follows/ratings/reports, co-op progress receipts and season history/reward receipts. It excludes password hashes, session/recovery digests, historical external identifiers, raw storage keys, other people's private notes and internal authoritative game state (including future cards, held inputs and mine locations). Binary files remain separate authenticated downloads. Exports use a repeatable-read snapshot and no-store response.

Deletion requires the exact phrase `DELETE username` and recent password authentication. Pending marketplace offers and active multiplayer poker stakes are cancelled/refunded transactionally before deletion. It deletes the account and sessions, authored messages, private classes/files, creations, saves and currency records. Server and party leadership transfers to the earliest remaining member; empty owned communities are removed. Other members' messages and school records remain. Archived multiplayer summaries remove the deleted player's identifier. Owner accounts require a separate platform ownership transfer before deletion. Administrative audit records survive deletion by design.

Private blob keys are queued in `storage_cleanup_jobs` in the same deletion transaction. Failed storage deletes remain retryable. The bounded operations worker schedules cleanup, reconciliation, school trash, reminders and backups; see [OPERATIONS](OPERATIONS.md). A coalesced background wakeup is also requested after deletion and discarded chat uploads. User responses do not wait for remote deletes. Retries rotate by last attempt so failing old keys do not starve new jobs. Set `STORAGE_CLEANUP_IMMEDIATE=false` for scheduled-only cleanup. Cleanup rechecks live references under the binding/key lock, and shares the backup bytes lock so a referenced snapshot object cannot disappear during copying. Orphan reconciliation is a separate age-gated provider-aware operation; it does not remove private metadata for missing bytes.

Focus Mode is a persistent account preference. It prioritizes Classes and upcoming assignments on Home, hides the party launcher, and offers direct Classes navigation. Users can exit it at any time; it does not disguise the platform or disable access to games.

Database tests cover export privacy, exact confirmation, owner protection, session removal, shared leadership and blob cleanup. Browser tests cover actual export downloads, deletion/revoked cookies, preservation of another person's note and Focus Mode across reloads.
