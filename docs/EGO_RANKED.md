# Ego Trip authoritative ranked foundation

Ranked solo offers a server-simulated eight-boss gauntlet and a forty-room/eight-district campaign. Both remain separate from the editable casual checkpoint. The server owns combat, route offers, encounters, event choices, weapons, upgrades, resources and completion. Casual saves never feed ranked state, scores, unlocks, currency or achievements. Migration 032 additively extends the persisted mode constraint and introduces the campaign completion achievement.

## Commands and simulation

`GET /api/games/ego-trip/ranked` returns the signed-in user's current/most recent run, recent run summaries and permanent progress. It never accepts a target user. `POST .../ranked/start` accepts mode (`boss-gauntlet` or `campaign`), an unlocked weapon, difficulty, bounded challenge modifiers and an unlocked starting helper. Seeds are generated by the server. Only one active run across both modes is permitted per account.

`POST .../ranked/intent` accepts `runId`, `expectedRevision`, a command and its bounded payload. Commands include movement/aim/fire/dash controls, server-offered mods and routes, available event responses, server-priced shop items, continuing and abandonment. No score, health, damage, completion claim, elapsed duration or permanent progress is accepted. Campaign invariants bind the current room, cleared rooms, route history, offered route IDs and boss count before mutation. Invented routes and repeated event/route transitions reject.

Every command locks the owner's record and run. Revision conflicts reject duplicate or reordered commands. Input updates are limited to one per 40 milliseconds; the client sends approximately eight per second. Accepted input advances the previously held controls through fixed steps of at most 25 milliseconds using elapsed server time. The newly supplied controls apply from that instant. Repeated requests at the same instant cannot accelerate the simulation.

A request gap longer than one second freezes combat and clears held controls. This makes suspended tabs/reconnects recoverable without applying minutes of held fire or killing the player off-screen. Ranking time includes the full wall-clock interval, including pauses and disconnects. Runs expire after 24 hours on their next intent; an expired active record can also be abandoned. Background simulation, replay re-execution and anti-bot detection are not implemented.

## Records and version compatibility

`ego_ranked_runs` records the owner, server seed, game version/content fingerprint, selected mode, difficulty, modifiers, validation status, timestamps, completion time, deaths, final boss and statistics. Campaign statistics include routes, rooms, secrets, weapons, upgrades and resources. Canonical engine state remains in PostgreSQL. The owner receives a renderable snapshot; other users cannot fetch or control that run.

Engine changes must bump `EGO_RANKED_VERSION`. Current version is `ego-ranked-4.0.0`; the fingerprint includes shared journey mission, pressure, sustain, movement and build-budget rules alongside content. Content changes additionally alter the fingerprint automatically. An active run from an incompatible version is preserved and cannot continue under changed rules. The user can deliberately abandon it; this marks the version as preserved and makes no new progression grants. Old casual checkpoints remain governed by their existing compatibility conversion.

## Permanent progress, rewards and rankings

Server-simulated boss defeats grant each associated achievement once, unlock the next weapon/helper and earn bounded insight. Defeating Austin unlocks volatile difficulty and fragile/no-helper challenge modifiers. Permanent unlocks improve the available choices; they do not import casual health or damage upgrades.

A full validated gauntlet or campaign grants its mode-specific completion achievement, 15 fictional TellCoins journaled with the unique run ID, ten insight and the earned-only Verified Confidence badge. Campaign settlement requires forty canonical clears, a forty-entry route history and eight defeated bosses. Achievement rewards use existing transactional XP/TellCoin/notification helpers. Repeated/concurrent completion cannot duplicate rewards. The badge cannot be purchased or equipped before it is earned.

Only full completions enter the leaderboard, with server wall-clock completion time. Existing gauntlet categories remain. Campaign uses three bounded categories: `campaign`, `campaign-volatile`, and `campaign-challenge`. Metadata retains the exact modifiers, run ID, start time, seed, version, validation and duration, allowing reset epochs to exclude old runs. Casual scores remain unranked. Daily/weekly boards use platform period filtering; shared daily/weekly campaign seeds are not implemented.

Verified full co-op wins share permanent weapon/helper options and insight through independent once-only receipts (migration 036). They grant no ranked achievements, ranked completion count, score, XP or currency. Later ranked boss victories still grant their ranked achievements even if co-op unlocked the option first. The progress view distinguishes ranked/co-op clears and displays verified co-op discoveries. Account export includes owned run summaries, permanent progress and co-op receipt summaries rather than canonical combat state or held controls. Account deletion cascades these records.

## Validation and remaining scope

Pure tests cover timing, deterministic seeds, frozen reconnects, forgery, choices, challenge gates, inconsistent state, forty-room transitions and no-helper events. PostgreSQL cases exercise the full campaign sequence through authenticated intent handlers, campaign leaderboard placement and once-only completion settlement alongside ownership/revision/ledger/version checks. Three focused Chromium cases passed with real gauntlet/campaign movement and hits, reload recovery, forged outcome/route rejection, cross-user denial and casual-save preservation. Database completion fixtures shorten server targets; browser cases do not claim full human campaign completion.

Ranked co-op, shared daily/weekly seeds, replay inspection, polished presentation and production latency/load/abuse validation remain. The ranked canvas renders combat geometry, enemies, objectives and campaign choices rather than the entire Phaser presentation. [Current journey measurements](EGO_JOURNEY_PACING.md) show 140 complete simulations at 42.63 active minutes median. The campaign targets 45–60 minutes with human choices/execution; an actual human pacing study has not been performed. Old shortened settlement fixtures explicitly restore compact legacy checkpoints and retain all reward/ranking assertions.

New ranked campaigns use the shared ordered courier/ward/escort missions and three gated phases per boss. The renderer shows the current mission and shield status. The gauntlet remains a shorter separate mode. Actual HTTPS deployment/native-account browser evidence appears in [current verification](VERIFICATION_DEPLOYMENT_2026-10-04.md).
